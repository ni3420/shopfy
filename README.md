# Shopfy 🛒
**A Modern, High-Performance E-commerce Experience.**

Shopfy is a full-stack e-commerce application built with a focus on speed, security, and a seamless user experience. It leverages **React 19**, **Appwrite** for Backend-as-a-Service, and **TanStack Query** for robust server-state management.

---

## 🚀 Features

- **Authentication:** Secure login and registration powered by Appwrite Auth.
- **Dynamic Cart:** Real-time cart updates with optimistic UI rendering via React Query.
- **Unified Checkout:** Smart checkout flow handling both direct "Buy Now" and multi-item cart purchases.
- **Product Discovery:** Category filtering and "Hot Deals" showcase.
- **Responsive Design:** Mobile-first approach using Tailwind CSS 4.0.
- **State Management:** Global UI and Auth state managed via **React Context API**.

---

## 🛠️ Tech Stack

### Frontend
- **Framework:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Routing:** [React Router v7](https://reactrouter.com/)

### Data Fetching & State
- **Server State:** [TanStack Query v5](https://tanstack.com/query/latest)
- **Global State:** [React Context API](https://react.legacy.reactjs.org/docs/context.html)
- **Forms:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)

### Backend (BaaS)
- **Platform:** [Appwrite](https://appwrite.io/) (Auth, Database, Storage)

### Tooling
- **Bundler:** [Vite v8](https://vitejs.dev/)
- **Notifications:** [React Hot Toast](https://react-hot-toast.com/)
